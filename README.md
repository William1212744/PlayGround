## Nightfall Strike

A top-down survival shooter that runs directly in the browser with no build step. Open `index.html` or serve this folder with any static web server.

- **Move:** WASD or arrow keys (touch joystick on mobile)
- **Aim and fire:** Mouse and hold click (touch the playfield to aim; use FIRE to shoot)
- **Objective:** Survive, eliminate hostiles, and advance through waves. Pickups restore health.
